KEY CONCEPT 01 Mo4-L1: What is Motion?
Textbook Page 92

Key Concept Question

What information do you need to describe an object’s motion?

Official Answer Key

To completely describe an object’s motion, you need three pieces of information:

  1. Reference Point (จุดอ้างอิง): A stationary starting point used for comparison to detect a change in position.
  2. Distance (ระยะทาง): How far the object has moved from the reference point.
  3. Direction (ทิศทาง): Which way the object moved relative to the reference point (e.g., east, north, left).
Concise Student Response: You need a reference point, the distance moved, and the direction of motion.

KEY CONCEPT 02 Mo4-L1: What is Motion?
Textbook Page 95

Key Concept Question

How can a graph help you understand an object’s motion?

Official Answer Key

A motion graph visually shows how an object’s distance or speed changes over time, making movement patterns easy to compare:

  • Distance–Time Graph: A steeper slope indicates a faster speed; a gentle slope indicates a slower speed; a flat horizontal line means the object is stopped (at rest).
  • Speed–Time Graph: A steeper slope indicates greater acceleration (speeding up or slowing down faster); a flat line indicates constant speed.
Concise Student Response: A graph shows how an object’s distance or speed changes over time; the steepness of the line shows whether it moves fast, slow, or stops.

KEY CONCEPT 03 Mo4-L2: How to Describe an Object’s Position?
Textbook Page 97

Key Concept Question

How does the description of an object’s position depend on a reference point?

Official Answer Key

An object’s position (ตำแหน่ง) is defined as its distance in a certain direction from a chosen reference point. Because every measurement begins at that starting point:

  • Without a reference point, you cannot state how far away or in which direction an object is located.
  • Changing the reference point changes the description of the object’s position (its measured distance and/or direction), even though the object itself has not moved.
Concise Student Response: A position is an object’s distance and direction from a reference point; if you change the reference point, the description of the position changes too.

KEY CONCEPT 04 Mo4-L2: How to Describe an Object’s Position?
Textbook Page 99

Key Concept Question

How can you describe the position of an object in two dimensions?

Official Answer Key

To describe an object’s position in two dimensions (สองมิติ), follow three steps:

  1. Choose a Reference Point: Identify a fixed origin (0, 0).
  2. Specify Two Reference Directions: Select two perpendicular axes, such as East/West (x-axis) and North/South (y-axis).
  3. State the Distance in Each Direction: Give how far the object is from the reference point along each direction (e.g., 4 m East and 3 m North).
Concise Student Response: Choose a reference point and give the distance in two perpendicular directions (for example, East and North).

KEY CONCEPT 05 Mo4-L3: How Do We Describe Changes in Position?
Textbook Page 102

Key Concept Question

What is the difference between distance and displacement?

Official Answer Key

Distance (ระยะทาง) is the total length of the path an object travels, regardless of direction. Displacement (การกระจัด) is the straight-line distance and direction between an object’s initial (starting) position and its final (ending) position.

Concise Student Response: Distance depends on the entire path taken; displacement is the straight-line distance and direction from start to finish.

Figure 3.1 — Winding Path (Distance) vs. Direct Vector (Displacement)

Feature Distance (ระยะทาง) Displacement (การกระจัด)
Definition Total length of the actual path traveled. Straight-line distance and direction from start to finish.
Direction Required? No (Scalar quantity — magnitude only). Yes (Vector quantity — magnitude + direction).
Round-Trip Example Walk 5 m East + 5 m West = 10 m. Walk 5 m East + 5 m West = 0 m (back at start).
KEY CONCEPT 06 Mo4-L4: What are Speed, Velocity and Acceleration?
Textbook Page 106

Key Concept Question

Can an object traveling at a constant speed have a changing velocity? Why or why not?

Official Answer Key

Yes. Because velocity (ความเร็ว) depends on both speed and direction, an object moving at a constant speed has a changing velocity whenever its direction changes—for example, when a car turns a corner or moves along a circular path.

Concise Student Response: Yes, because velocity includes direction; if the object turns or moves in a circle, its direction—and therefore its velocity—changes.

KEY CONCEPT 07 What are Speed, Velocity and Acceleration?
Textbook Page 108

Key Concept Question

How does acceleration differ from velocity?

Official Answer Key

Velocity (ความเร็ว) measures how fast an object changes its position in a specific direction (rate of displacement over time), whereas acceleration (ความเร่ง) measures the rate at which an object’s velocity changes over time (by speeding up, slowing down, or changing direction).

Comparison Point Velocity (v) — ความเร็ว Acceleration (a) — ความเร่ง
What It Measures Rate of change of position (displacement). Rate of change of velocity.
Equation v = displacement ÷ time a = (vfinal − vinitial) ÷ time
Standard SI Unit Meters per second (m/s) + direction Meters per second squared (m/s2) + direction
Constant Motion Case Non-zero if moving steadily in a straight line (e.g., 20 m/s East). Zero (0 m/s2) when moving at constant speed in a straight line.
KEY CONCEPT 08 What are Speed and Velocity?
Textbook Page 111

Key Concept Question

What is Speed?

Official Answer Key

Speed (อัตราเร็ว) is a measure of the distance an object travels in a unit of time (s = d ÷ t). Unlike velocity, speed describes only how fast an object moves without direction.

Common Units: Meters per second (m/s, standard SI unit), kilometers per hour (km/h), and miles per hour (mph).

Concise Student Response: Speed is the distance an object travels per unit of time (s = d/t), measured in m/s or km/h.

KEY CONCEPT 09 What are Speed and Velocity?
Textbook Page 118

Key Concept Question

How can velocity change?

Official Answer Key

Velocity changes in any of three ways:

  1. When speed changes: The object speeds up or slows down while moving in the same direction.
  2. When direction changes: The object turns or curves while keeping a constant speed.
  3. When both speed and direction change: The object speeds up or slows down while turning.
Textbook Summary Answer: Velocity changes when the speed of an object changes, when the direction that the object moves changes, or when both the speed and the direction change.

KEY CONCEPT 10 What is Acceleration?
Textbook Page 120

Key Concept Question

What are three ways an object can accelerate?

Official Answer Key

Because acceleration (ความเร่ง) is any change in velocity over time, an object accelerates when:

  1. Increasing Speed (Speeding Up): Positive acceleration in the direction of motion.
  2. Decreasing Speed (Slowing Down): Negative acceleration (deceleration) opposite to the direction of motion.
  3. Changing Direction: Turning or curving (such as a car turning through an intersection, even at a constant speed).
Concise Student Response: An object accelerates by (1) increasing speed, (2) decreasing speed, or (3) changing direction.

KEY CONCEPT 11 What is Acceleration?
Textbook Page 125

Key Concept Question

What does a speed–time graph show about the motion of an object?

Official Answer Key

A speed–time graph shows how an object’s speed changes over time:

  • Slope of the Line = Acceleration: An upward slope means speeding up (positive acceleration); a horizontal flat line means constant speed (zero acceleration); a downward slope means slowing down (negative acceleration).
  • Area Under the Line = Distance Traveled: Calculating the geometric area beneath the plotted line gives the total distance covered (as shown in the area calculation on page 125).
Textbook Summary Answer: A speed–time graph shows how speed changes over time.
